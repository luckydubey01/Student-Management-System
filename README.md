# Student-Management-System
This project is created as a learning project to practice Java fundamentals and basic programming concepts.

Features

- Add student details
- Display All Students  details
- Search students by ID
- Update students information
- Delete students records
- Exit

Technologies Used

- Java
- Java Fundamentals
- Object-Oriented Programming (OOP)
- Collections / Arrays (as used in the project)

Purpose

This project was developed to improve my understanding of Java programming and gain practical experience by building a simple real-world application.

Learning Outcomes

- Practiced Java fundamentals
- Improved understanding of OOP concepts
- Learned how to organize Java code
- Developed problem-solving and programming skills

Project Status

Completed as a beginner learning project.
